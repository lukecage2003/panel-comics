Politique de confidentialité

Version du 27 novembre 2026

Panel est une application pour gérer sa collection de comics et échanger avec d’autres collectionneurs. Elle fonctionne d’abord sur votre appareil : sans compte, rien ne quitte votre téléphone ou votre ordinateur. Cette page explique ce qui change quand vous créez un compte.

1. Qui est responsable de vos données

Panel est édité par Primestone Media. Pour toute question sur vos données ou pour exercer vos droits : primestone.mediapro@gmail.com.

2. Sans compte : tout reste sur votre appareil

Votre collection, votre wishlist, votre Pull list, vos emplacements, vos lectures, vos notes, vos fichiers PDF et CBZ et vos réglages sont enregistrés dans le stockage de votre navigateur ou de l’application (stockage local et IndexedDB). Panel ne les reçoit pas.

Quand vous cherchez un numéro ou une couverture, Panel interroge des bases de données de comics (Comic Vine, par un relais hébergé chez notre fournisseur Supabase ; Metron ; Grand Comics Database ; wikis Fandom). Ces services reçoivent le texte de votre recherche (titre, numéro, éditeur), jamais votre identité ni votre collection.

4. Base légale

Le compte, la sauvegarde, la communauté et la messagerie sont fournis parce que vous les demandez : le traitement repose sur l’exécution du service (article 6.1.b du RGPD). Les journaux de sécurité reposent sur notre intérêt légitime à protéger les comptes (article 6.1.f).

5. Qui d’autre traite vos données

  • Supabase (base de données, connexion, stockage des fichiers chiffrés, envoi des e-mails de compte) : serveurs dans l’Union européenne (Paris). Supabase est une société américaine qui s’appuie sur Amazon Web Services ; les transferts éventuels hors de l’Union européenne sont encadrés par les clauses contractuelles types de la Commission européenne.
  • GitHub Pages (hébergement du site) : reçoit, comme tout hébergeur, l’adresse IP des visiteurs.
  • Google, seulement si vous choisissez « Continuer avec Google ».
  • Pwned Passwords (service gratuit de HaveIBeenPwned) : quand vous choisissez un mot de passe, Panel vérifie qu’il ne figure pas dans une fuite connue. Seuls les 5 premiers caractères d’une empreinte du mot de passe sont envoyés ; ni le mot de passe, ni votre adresse, ni l’empreinte complète ne quittent votre appareil.
  • Retranscription des vocaux : si vous l’activez dans le navigateur, le service de reconnaissance vocale de ce navigateur (par exemple Google pour Chrome) reçoit l’enregistrement. Elle est désactivée tant que vous ne la choisissez pas.

6. Combien de temps

Vos données de compte sont gardées tant que le compte existe. Quand vous le supprimez, elles sont effacées immédiatement de notre base. Les copies de sécurité du fournisseur, s’il y en a, disparaissent à leur expiration. Les signalements et les décisions de modération qui vous concernent sont conservés sans lien avec votre compte, pour la sécurité de la communauté.

7. Vos droits

Vous pouvez à tout moment, depuis Réglages → Compte :

  • télécharger vos données (bouton « Exporter mes données », au format JSON) : droit d’accès et de portabilité ;
  • corriger votre profil et votre collection directement dans l’application ;
  • supprimer votre compte et ses données (bouton « Supprimer mon compte »). La collection de votre appareil n’est pas touchée.

Vous pouvez aussi nous écrire à primestone.mediapro@gmail.com pour exercer vos droits d’accès, de rectification, d’effacement, de limitation, d’opposition et de portabilité. Nous répondons dans un délai d’un mois. Si vous estimez que vos droits ne sont pas respectés, vous pouvez saisir la CNIL (cnil.fr).

8. Mineurs

Panel n’ouvre pas de compte avant 13 ans. Entre 13 et 14 ans, l’accord d’un parent ou d’un tuteur est demandé. Les profils des moins de 18 ans ne peuvent pas être publics, et la messagerie privée est réservée aux adultes.

9. Sécurité

Les échanges passent par des connexions chiffrées (HTTPS). L’accès aux données est restreint compte par compte dans la base. Les messages et vocaux sont chiffrés sur votre appareil avant l’envoi. La double authentification par application est proposée dans Réglages → Compte. En cas de violation de données présentant un risque, nous prévenons la CNIL et, si le risque est élevé, les personnes concernées.

10. Stockage sur votre appareil

Panel enregistre sur votre appareil vos données locales et, si vous êtes connecté, votre jeton de session. Ce stockage est nécessaire au fonctionnement du service ; il n’y a pas de cookie publicitaire.

11. Modifications

Si cette politique change de façon importante, nous l’indiquerons dans l’application avant que le changement s’applique. La date de version figure en haut de cette page.
